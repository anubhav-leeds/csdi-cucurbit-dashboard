# CSDI-informed cucurbit sowing-window climatic analogue dashboard

This repository hosts a prototype India-scale dashboard for CSDI-informed cucurbit sowing-window climatic analogues.

The dashboard maps CSDI-informed climatic analogues to experimentally tested sowing-window classes. It does not predict yield, observed CSDI, physiological traits, biochemical traits, or exact sowing dates. It is a research prototype and not an operational farmer advisory tool.
